プライバシーポリシー

工場用の日報アプリ「製作日報」（以下「本アプリ」）

1. 基本的な考え方

本アプリは、運営者のサーバーを持ちません。本アプリで入力したデータは、原則として入力した端末の中だけに保存されます。運営者がそれらのデータを見たり集めたりすることはありません。

2. 端末の中に保存するもの

  • 作業員の名前、物件名・工事番号、工程の名前
  • 日ごとの記録（えらんだ物件・工程・時間・休みの種類・ひとこと）
  • 管理画面のパスワード、表示の設定

物件の一覧（Excel・CSV・受注残報告書など）を読み込んだ場合は、物件名と工事番号だけを取り出して保存します。読み込んだファイルそのものは保存せず、外部にも送りません。

これらは端末内のアプリ用の保存領域に保存され、外部には送られません（下の「3」を使った場合を除きます）。

3. Googleドライブとの同期（使う場合のみ）

「Googleドライブにつなぐ」を押した場合に限り、あなたのGoogleアカウントでログインし、上のデータ（管理画面のパスワードを除く）をあなた自身のGoogleドライブの「製作日報データ」フォルダに保存・読み込みします。Excelをドライブに保存する場合も同じです。

  • 本アプリは、Googleへのログインの設定を同じ運営者のアプリ「ピタ測」と共用しています。そのため、Googleの許可画面には「ピタ測」と表示されます。
  • 本アプリが求める権限は「このアプリが作ったファイルだけを読み書きする」もの（drive.file）です。ドライブにあるほかのファイルを見ることはできません。
  • データはあなたの端末とGoogleドライブの間で直接やり取りされ、運営者のもとには届きません。
  • Googleから受け取った情報は、同期の機能を提供するためだけに使い、ほかの目的に使ったり、第三者に渡したり、広告に使ったりしません。本アプリによるGoogle APIから受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。
  • 「同期をやめる」を押すと、本アプリはドライブにアクセスしなくなります。Googleアカウントの設定からも、いつでもアクセスを取り消せます。

4. 使っていないもの

  • 広告は表示しません。
  • 利用状況を調べる解析ツールは使っていません。
  • カメラ・位置情報・連絡先・電話番号などは使いません。

5. データを消すには

  • 本アプリの管理画面で、物件・作業員・工程・記録を削除できます。
  • ブラウザのサイトデータを削除するか、ホーム画面に追加したアプリを削除すると、端末の中のデータはすべて消えます。
  • Googleドライブに保存したデータは、ドライブの「製作日報データ」フォルダを削除すると消えます。
