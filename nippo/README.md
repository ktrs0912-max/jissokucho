# 製作日報（工場の作業員用）

作業員がその日にどの物件の製品を製作したかを、タブレットでかんたんに入力するアプリです。
公開先（GitHub Pages）：`https://ktrs0912-max.github.io/jissokucho/nippo/`

## 使い方
1. タブレットのブラウザで上のURLを開き、「ホーム画面に追加」する（電波がなくても開けます）
2. 「管理」→「作業員」で名前をなおす（最初は作業員A〜Eの5人が入っています）
3. 「管理」→「工程」で工程を確かめる（最初は切断・溶接・塗装。追加・名前の変更・並べ替えができます）
4. 「管理」→「物件」で工事番号と物件名を登録する。製作が終わった物件は「完了にする」と入力画面から消えます
5. 作業員は自分の名前をタップ → 物件をタップ（いくつでも） → 物件ごとに工程をタップ（いくつでも。必ずえらぶ） → 「保存する」
   - 時間は分かれば入れる（なくても保存できます）
   - 「前回と同じ」で前回の物件と工程をそのままえらべます
   - 書き忘れた日は、上の「‹」で日付を戻して入力できます
   - 休みの日は、名前をタップして「休み」「有給」「欠勤」を押すだけで保存されます
   - ホームに「入れ忘れがあります」と出たら、日付をタップしてその日を入力します
     （日曜以外で、だれかが作業を入れているのに入力がない日を入れ忘れとみなします）
6. 月末に「管理」→「記録・出力」で月をえらんで Excel / CSV に出す

## Excelの中身
- 明細：日付・作業員・区分（作業／休み／有給／欠勤）・工事番号・物件名・工程・時間・人工・ひとこと（1行1物件）
- 日別：日付×作業員の表
- 物件別：物件ごとの、作業員別の人工・人工合計・時間合計・製作した日数
- 人別：作業した日・休み・有給・欠勤・入れ忘れの日数
- 工程別：物件ごとの、工程別の人工（1物件に工程を2つえらんだ日は半分ずつ）
  - 人工は1日を1として、2物件なら0.5ずつ（全部に時間を入れた日は時間の割合）

## Googleドライブ同期
「管理」→「その他」→「Googleドライブにつなぐ」。ドライブの「製作日報データ/nippo.json」に保存され、
同じGoogleアカウントでつないだ別のタブレットや事務所のパソコンでも同じ記録が見られます。
- 同じ物を両方で書き換えた時は、あとから書き換えたほうが残ります。消した物は「消した印」で他の端末からも消えます
- 電波がない間の入力は、電波が戻ったら送ります。開いている間は1分ごとに他の端末の入力を取りに行きます
- Googleの決まりで1時間ごとにつなぎ直しが必要です。切れている時は「保存する」「管理」を押した時に自動でつなぎ直します
- 「記録・出力」→「Excelをドライブに保存」で「製作日報データ/Excel出力」に保存できます
- ログインの設定（OAuthクライアント）はピタ測と同じ物を使っています（同じ公開先なので使えます）

## データの置き場所
ドライブ同期を使っていない時は、このタブレットの中だけに保存されます。「その他」→「バックアップを保存」で時々ファイルに残してください。
