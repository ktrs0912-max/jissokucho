# 製作日報（工場の作業員用）

作業員がその日にどの物件の製品を製作したかを、タブレットでかんたんに入力するアプリです。
公開先（GitHub Pages）：`https://ktrs0912-max.github.io/jissokucho/nippo/`

## 使い方
1. タブレットのブラウザで上のURLを開き、「ホーム画面に追加」する（電波がなくても開けます）
2. 「管理」→「作業員」で名前をなおす（最初は作業員A〜Eの5人が入っています）
3. 「管理」→「工程」で工程を確かめる（最初は切断・溶接・塗装。追加・名前の変更・並べ替えができます）
4. 「管理」→「物件」で工事番号と物件名を登録する。製作が終わった物件は「完了にする」と入力画面から消えます
5. 作業員は自分の名前をタップ → 物件をタップ（いくつでも） → 物件ごとに工程をタップ（いくつでも） → 「保存する」
   - 時間は分かれば入れる（なくても保存できます）
   - 「前回と同じ」で前回の物件と工程をそのままえらべます
   - 書き忘れた日は、上の「‹」で日付を戻して入力できます
6. 月末に「管理」→「記録・出力」で月をえらんで Excel / CSV に出す

## Excelの中身
- 明細：日付・作業員・工事番号・物件名・工程・時間・人工・ひとこと（1行1物件）
- 日別：日付×作業員の表
- 物件別：物件ごとの、作業員別の人工・人工合計・時間合計・製作した日数
- 工程別：物件ごとの、工程別の人工（1物件に工程を2つえらんだ日は半分ずつ）
  - 人工は1日を1として、2物件なら0.5ずつ（全部に時間を入れた日は時間の割合）

## データの置き場所
このタブレットの中だけに保存されます。「その他」→「バックアップを保存」で時々ファイルに残してください。
