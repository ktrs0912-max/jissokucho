プライバシーポリシー

アプリ「ピタ測」（以下「本アプリ」）

1. 基本的な考え方

本アプリは、作者が運営するサーバーを持ちません。図面・番号・実測値・写真・書き込みなど、あなたが本アプリで作るデータは、原則としてあなたの端末の中だけに保存されます。作者がそれらのデータを見たり集めたりすることはありません。

2. 端末の中に保存するもの

  • 取り込んだ図面（PDF・画像）、現場名、位置の名前、番号の位置、実測値、メモ
  • 本アプリで撮影した写真と、図面・写真への書き込み
  • 表示の設定（番号の丸の大きさ、タッチペンを使ったかどうか など）

これらは端末内のアプリ用の保存領域に保存され、外部には送られません（下の「3」「4」を使った場合を除きます）。

3. Googleドライブとの同期（使う場合のみ）

「ドライブとつなぐ」を押した場合に限り、あなたのGoogleアカウントでログインし、上のデータをあなた自身のGoogleドライブの「ピタ測データ」フォルダに保存・読み込みします。Excelをドライブに保存する場合も同じです。

  • 本アプリが求める権限は「このアプリが作ったファイルだけを読み書きする」もの（drive.file）です。ドライブにあるほかのファイルを見ることはできません。
  • データはあなたの端末とGoogleドライブの間で直接やり取りされ、作者のもとには届きません。
  • Googleから受け取った情報は、同期の機能を提供するためだけに使い、ほかの目的に使ったり、第三者に渡したり、広告に使ったりしません。本アプリによるGoogle APIから受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。
  • 「つなぐのをやめる」を押すと、本アプリはドライブにアクセスしなくなります。Googleアカウントの設定からも、いつでもアクセスを取り消せます。

4. 感想の送信（使う場合のみ）

「感想を送る」で送信した場合に限り、入力した内容（お仕事の種類、使った場面、便利だった機能、困ったこと、希望する価格、ほしい機能、連絡先）と本アプリの版が、Googleフォームを通じて作者に届きます。連絡先の入力は任意で、返事をする目的にだけ使います。送られた内容は本アプリの改善のためにだけ使い、第三者に渡しません。

5. カメラ

写真を撮る機能を使う時だけカメラを使います。撮った写真は端末の中に保存され、上の「3」を使った場合を除き外部には送られません。

6. 使っていないもの

  • 広告は表示しません。
  • 利用状況を調べる解析ツールは使っていません。
  • 位置情報・連絡先・電話番号などは使いません。

7. データを消すには

  • 本アプリの中で、現場・図面・位置・写真を削除できます。
  • 本アプリをアンインストールするか、ブラウザのサイトデータを削除すると、端末の中のデータはすべて消えます。
  • Googleドライブに保存したデータは、ドライブの「ピタ測データ」フォルダを削除すると消えます。
  • 送った感想を消してほしい場合は、下の連絡先までご連絡ください。
